## About

File Organizer is a Python automation project that scans a folder and automatically sorts files into categorized folders such as Images, Videos, Documents, PDFs, and Music.

---

## Features

- Organize files automatically
- Categorize by file extension
- Create folders if they don't exist
- Supports multiple file types
- Simple command-line interface
