## About

Text to Speech is a Python application that converts user-provided text into spoken audio using the `pyttsx3` library.

The application works offline using the speech engine available on the local system.

---

## Features

- Convert text into speech
- Offline speech synthesis
- Adjustable speech rate
- Adjustable volume
- Save generated speech as an audio file
