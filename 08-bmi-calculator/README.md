## About

BMI Calculator is a simple Python command-line application that calculates the Body Mass Index (BMI) based on the user's height and weight. It also classifies the BMI into standard health categories.

---

## Features

- Calculate BMI instantly
- Classify BMI category
- Simple command-line interface
- Beginner-friendly
