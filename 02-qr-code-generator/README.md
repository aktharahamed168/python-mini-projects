## About

QR Code Generator is a simple Python application that converts any text or URL into a QR code image.

This project demonstrates how to generate QR codes using the **qrcode** library.

---

## Features

- Generate QR codes from text
- Generate QR codes from URLs
- Save QR code as PNG
- Simple command-line interface

---

## Tech Stack

| Technology | Description |
|------------|-------------|
| Python | Programming Language |
