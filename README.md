## About

This repository contains a collection of Python mini-projects covering core programming concepts, file handling, APIs, automation, image processing, and more.

Each project is organized in its own folder with:

- Source code
- README
- Requirements
- Screenshot
- Sample output

The goal is to improve problem-solving skills by building real-world applications.
