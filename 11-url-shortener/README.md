## About

URL Shortener is a Python command-line application that converts long URLs into short, easy-to-share links using the CleanURI API.

---

## Features

- Shorten long URLs
- Fast API response
- Easy command-line interface
- Lightweight and beginner-friendly

---

## Tech Stack

| Technology | Purpose |
|------------|---------|
| Python | Programming Language |
| requests | HTTP Requests |
