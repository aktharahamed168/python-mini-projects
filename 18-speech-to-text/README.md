## About

Speech to Text is a Python application that captures audio from a microphone and converts spoken words into text using speech recognition.

The application can also save the recognized text as a local transcription file.

---

## Features

- Capture audio through microphone
- Convert speech into text
- Handle unclear audio
- Handle recognition service errors
- Save transcription locally
