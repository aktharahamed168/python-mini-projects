## About

Password Generator is a simple Python application that creates strong and random passwords based on the length entered by the user.

The generated password contains:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

---

## Features

- Generate passwords of any length
- Strong random password generation
- Simple command-line interface
- Lightweight and easy to use

```bash
cd python-interview-preparation/01-password-generator
```

