## About

The Weather App is a Python command-line application that retrieves current weather information for any city using the OpenWeather API.

---

## Features

- Search weather by city
- Current temperature
- Humidity
- Wind speed
- Weather description
- Real-time API data

---

## Tech Stack

| Technology | Purpose |
|------------|---------|
| Python | Programming Language |
| requests | HTTP Requests |
| OpenWeather API | Weather Data |
